## ✨ Feature Highlights — A Closer Look Under the Hood

Every feature below was shaped by feedback from simulation enthusiasts who wanted *more signal, less noise*.

### 🎛️ Adaptive Training Dashboard
The core of the suite. A responsive UI panel that reorganizes itself based on the vehicle class you choose — sports, off-road, truck, or compact. Widgets snap into place like magnetic tool trays, so the information you actually need is never more than a glance away.

### 🌍 Multilingual Interface (14 Languages)
From Portuguese to Japanese, the interface speaks your language. Localization was handled by native speakers, not machines, which means menu labels read like they were written by someone who actually drives.

### 🕒 Round-the-Clock Assistance Desk
A 24/7 customer support channel stands behind every session. Whether you hit a configuration snag at 3 a.m. or need guidance routing your first scenario pack, someone is on the other end. Response windows average under an hour during peak periods.

### ⚡ Responsive Control Layer
Input latency was cut dramatically compared to the previous generation. Steering feel, throttle response, and brake modulation now translate in near real-time, even on wireless peripherals.

### 🧩 Scenario Loom
A modular system for weaving together practice scenarios — slalom runs, hill climbs, wet-braking drills — into a single continuous playlist. Save it, share the manifest, or reshuffle with one click.

### 📊 Telemetry Snapshot Tool
Capture a moment of your run and export a compact summary: speed, G-loads, wheel slip, and throttle trace. Perfect for reviewing a bad corner later or comparing setups between sessions.

### 🧱 Ghost Lane Replay
A lightweight replay companion that lets you race against a semi-transparent echo of your previous best. No cloud account required — everything stays local.

### 🔋 Eco-Render Mode
For laptops and modest desktops, this mode trims background overlays to keep your frame budget where it matters. Turns a stuttering 45 FPS into a steady 60 with a single toggle.

### 🛡️ Session Guard
An autosave daemon that quietly protects your progress and profile settings. If the unexpected happens, Session Guard restores you to the last known good state without drama.

### 🧠 Smart Preset Memory
Profiles remember your preferred camera, control sensitivity, and overlay layout per vehicle. Jump between cars and the suite follows along.

## 🚀 Getting Started — The Path In

Setting up is less like installing software and more like parking a car in a well-lit garage. No cryptic commands, no terminal gymnastics.

### Step 1 — Acquire the Package
Locate the distribution archive for the 2026 release. The file is a self-contained bundle; you are not going to chase down a dozen separate dependencies.

### Step 2 — Unpack in a Clean Folder
Create a dedicated directory — something like `C:\DriveTrainer2026\` — and extract the contents there. Keeping it isolated makes future updates and cleanups effortless.

### Step 3 — Launch the Companion Shell
Inside the extracted folder you will find the primary executable. Double-click it. On first run, the suite performs a quick environment scan and configures itself for your display and controller.

### Step 4 — Pair with Your Driving Session
Open your simulation, then switch to the companion window. It will auto-detect an active session and dock its overlay. If you prefer, pin the overlay to a second monitor.

### Step 5 — Personalize
Open the Settings panel to choose your language, theme (Midnight, Daylight, or Amber), and overlay density. Profiles are stored locally and sync across sessions automatically.

### Step 6 — Learn the Ropes
The built-in Quick Tour runs for about two minutes and highlights every major panel. Skip it if you're impatient, but it's the fastest route to mastery.

## 🔍 Troubleshooting & Common Questions

**The overlay disappears when I alt-tab.**
Enable *Always On Top* in Settings → Overlay. Some fullscreen modes need borderless windowed instead.

**My controller isn't recognized.**
Open the Control Layer panel and re-run device detection. Wireless adapters occasionally need a replug.

**Frames drop after long sessions.**
Toggle Eco-Render Mode. Memory trimming runs automatically every twenty minutes.

**Language didn't change.**
Restart the shell after switching. Localization bundles load at startup.

**Antivirus flags the shell.**
This is a false positive common to unsigned utilities. Whitelist the folder if you trust the source, or verify the checksum in `/docs/checksums.txt`.

**Can I run it offline?**
Yes. Only update checks require connectivity, and those can be disabled entirely.
